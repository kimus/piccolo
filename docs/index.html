Piccolo

Install the Piccolo host CLI from GitHub Releases.

curl -fsSL https://kimus.github.io/piccolo/install.sh | sh

Install a specific version:

curl -fsSL https://kimus.github.io/piccolo/install.sh | sh -s -- --version 0.3.0

The installer downloads the matching archive, verifies checksums.txt, and installs only the host piccolo CLI.
